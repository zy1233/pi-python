# zypi User Guide

`zypi` is a terminal interface for a coding agent. These pages describe `zypi`. The agent is a separate program: the Python agent `pi_agent_cli`.

| --- | --- | --- |
| 1 | [Getting Started](01-getting-started.md) | Set up the model, start `zypi`, and the keys to learn first |
| 4 | [Slash Commands](04-slash-commands.md) | The built-in `/` commands and the command palette |
| 6 | [Theming and Appearance](06-theming.md) | Themes, `auto` mode, minimal mode, and `pager.toml` |
| 17 | [Sessions](17-sessions.md) | Where sessions are stored, how to continue a session, and how to export one |
| 21 | [Terminal Support and Troubleshooting](21-terminal-support.md) | `zypi doctor`, tmux, SSH, truecolor, and the clipboard |
| 22 | [Permissions and Safety](22-permissions-and-safety.md) | Permission modes, project trust, and what the agent sends to the model provider |
| 25 | [Status Line](25-status-line.md) | The status row and its stdin JSON contract (empty with the Python agent) |

The numbers in the first column are the numbers in the file names. Some numbers are not used, because the pages for the removed features are gone.
